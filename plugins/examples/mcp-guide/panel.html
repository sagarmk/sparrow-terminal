Resources (read-only)

sparrow://contextYour pane ID and environment
sparrow://panesAll open panes with IDs, names, cwds
sparrow://panes/{id}/outputRecent terminal output (last 200 lines)

Tools (actions)

create_paneOpen a new terminal pane
close_paneClose a pane
rename_paneRename a pane's tab label
write_to_pane Type text or send a signal (Ctrl-C/kill)
signal: SIGINT | SIGTERM focus: bool
run_command Run a command, capture ANSI-stripped output
wait_for: string focus: bool
screenshotCapture a PNG screenshot of a pane
clipboardRead or write the system clipboard

Typical Workflow

// 1 Discover your pane ID
read sparrow://context

// 2 See what panes are open
read sparrow://panes

// 3 Run a command, get clean output
sparrow_run_command({
  pane_id: "...",
  command: "npm test",
  wait_for: "PASS"
})

// 4 Interrupt a stuck process
sparrow_write_to_pane({
  pane_id: "...",
  signal: "SIGINT"
})

// 5 Open a new pane with a command
sparrow_create_pane({
  name: "build",
  command: "npm run dev"
})
